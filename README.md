# 2027 수능 LLM 채점표

2027학년도 대학수학능력시험(2026.11.19 시행)을 여러 LLM이 풀고 채점한 결과를 보는 대시보드입니다. 결과는 문항별 정오와 맞힌 문항 수, 원점수로만 보여 줍니다.

## 탭 구성

- **성적표**: 모델별 과목 원점수, 맞힌 문항 수, 총점
- **모델 상세**: 기준 모델 1개와 추가 모델 최대 4개를 나란히 봅니다. 국어·수학·영어·한국사·탐구 카드를 누르면 과목별 점수와 정오표, 틀린 문항 번호가 나옵니다.
- **과목별 정답수**: 과목마다 모든 모델의 맞힌 문항 수와 점수
- **AI 취약 분석**: 많이 틀린 문항, 회사마다 결과가 갈린 문항, 약한 과목, 로컬 모델로도 잘 나오는 과목
- **문항 정오표**, **오답 유형**, **로컬 vs 상용**
- **원문제**: 평가원 PDF를 직접 내려받아 불러오면 브라우저 안에서만 보여 줍니다. 이 저장소에는 문제 원문이 들어 있지 않습니다. 로컬 서버로 열 때는 [평가원 문제 및 정답 페이지](https://cdn.kice.re.kr/27dae-suneung/index.html)의 문제 PDF를 이름 그대로(`27DaeSuneung_1.pdf` 등) `pdf/` 폴더에 두면 자동으로 연결됩니다. `*.pdf`는 `.gitignore`에 들어 있어 올라가지 않습니다.

## 실행

정적 파일만 있습니다. `index.html`과 `data/` 폴더를 아무 웹 서버로 열면 됩니다. `file://`로 열면 데이터를 불러오지 못하므로 로컬 서버가 필요합니다.

```
npx serve .
```

## 데이터 출처

`data/`의 채점 결과와 모델 정보는 [CSAT-benchmark](https://hehee9.github.io/CSAT-benchmark/?exam=csat-2027&mode=default&scoreBasis=raw)에서 가져왔습니다. 채점은 시험 당일 공개된 가답안 기준이고, 모델당 1회 실행 결과입니다.

수능 문항의 저작권은 한국교육과정평가원에 있습니다.
