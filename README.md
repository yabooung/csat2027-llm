# 2027 수능 LLM 채점표

2027학년도 대학수학능력시험(2026.11.19 시행)을 여러 LLM이 풀고 채점한 결과를 보는 대시보드입니다. 결과는 문항별 정오와 맞힌 문항 수, 원점수로만 보여 줍니다.

## 탭 구성

- **성적표**: 모델별 과목 원점수, 맞힌 문항 수, 총점
- **모델 상세**: 기준 모델 1개와 추가 모델 최대 4개를 나란히 봅니다. 국어·수학·영어·한국사·탐구 카드를 누르면 과목별 점수와 정오표, 틀린 문항 번호가 나옵니다.
- **과목별 정답수**: 과목마다 모든 모델의 맞힌 문항 수와 점수
- **AI 취약 분석**: 많이 틀린 문항, 회사마다 결과가 갈린 문항, 약한 과목, 로컬 모델로도 잘 나오는 과목
- **문항 정오표**, **오답 유형**, **로컬 vs 상용**
- **내 답 확인**(문항 상세): 보기를 누르거나(숫자 키 1~5) 단답형 답을 입력하면 가답안으로 채점합니다. 보기에 마우스를 올리거나 누르면 그 답을 고른 모델 목록이 뜹니다. 상세 창은 원문제(공통 지문이 있으면 지문과 함께) → 내 답 확인 → 정답·모델 답안 순서입니다. '정답 보기'를 끄면(기본) 답하기 전까지 정답 값만 가리고, 맞힌 모델 수와 보기별 모델 수는 그대로 보여 줍니다. 내 답은 이 브라우저(localStorage)에만 남고, 과목별 기록은 원문제 탭에 모입니다.
- **원문제**: 평가원 PDF를 직접 내려받아 불러오면 브라우저 안에서만 보여 줍니다. 이 저장소에는 문제 원문이 들어 있지 않습니다. 로컬 서버로 열 때는 [평가원 문제 및 정답 페이지](https://cdn.kice.re.kr/27dae-suneung/index.html)의 문제 PDF를 이름 그대로(`27DaeSuneung_1.pdf` 등) `pdf/` 폴더에 두면 자동으로 연결됩니다. 이어서 `python -I tools/parse_kice.py pdf`를 실행하면 문항별 영역과 텍스트가 `pdf/questions.json`으로 만들어지고, 문항 상세에서 '문항'(문항 부분만 크게) · '문항+텍스트' · '쪽 전체' · '텍스트' 보기를 고를 수 있습니다. 수식은 글자 위치를 보고 `(분자)/(분모)`, `^`, `_`로 옮긴 근사이고, 그림·표는 '문항' 보기에서 봅니다. `pdf/` 폴더는 `.gitignore`에 들어 있어 올라가지 않습니다.

## 실행

정적 파일만 있습니다. `index.html`과 `data/` 폴더를 아무 웹 서버로 열면 됩니다. `file://`로 열면 데이터를 불러오지 못하므로 로컬 서버가 필요합니다.

```
npx serve .
```

## 데이터 출처

`data/`의 채점 결과와 모델 정보는 [CSAT-benchmark](https://hehee9.github.io/CSAT-benchmark/?exam=csat-2027&mode=default&scoreBasis=raw)에서 가져왔습니다. 채점은 시험 당일 공개된 가답안 기준이고, 모델당 1회 실행 결과입니다.

수능 문항의 저작권은 한국교육과정평가원에 있습니다.
